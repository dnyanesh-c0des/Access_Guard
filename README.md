# Access Guard

Access Guard is an interactive Python program for managing employee records, roles, tool permissions, access requests, and audit logs.

## Features

- Displays company and security information
- Onboards new employees
- Validates employee IDs and roles
- Generates employee email addresses and passwords
- Requests and grants or denies tool access
- Revokes employee access
- Updates employee records
- Compares employee access using sets
- Demonstrates list copying and cloning
- Generates a final employee and access-log report

## Requirements

- Python 3.9 or later
- No external libraries required

## Run the Program

Open a terminal in the project folder and run:

```bash
python access_guard.py
```

On Windows, you can also use:

```bash
py access_guard.py
```

## Program Workflow

The program contains these phases:

1. Company information and initial employee data
2. New employee onboarding
3. Access request portal
4. Tool audit and comparison
5. Access revocation and log analysis
6. Employee record updates
7. Employee data cloning
8. Final dashboard and report

- The program is interactive and requires user input.
- Data is stored temporarily in memory.
- Changes are not saved after the program exits.
- This project is intended for learning Python data structures, dictionaries, lists, sets, tuples
